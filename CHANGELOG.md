# Changelog

All notable changes to the IP Blacklist Checker project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2025-04-06

### Added
- More blacklists for comprehensive IP checking
- Detailed category-specific statistics in summary
- Enhanced visual indicators for trust levels

### Changed
- Improved trust score calculation algorithm
- Enhanced documentation with more detailed usage examples
- Refined categorization of blacklists for better organization

### Fixed
- Performance optimizations for faster blacklist checking
- Improved error handling for unreachable blacklists
- Fixed inconsistencies in result reporting

## [1.1.0] - 2024-11-10

### Added
- Python implementation with rich terminal output
- Live progress bar during blacklist checks
- Colorful terminal output with tables and panels
- Enhanced trust score visualization

### Changed
- Improved user interface with more detailed results
- Better handling of network timeouts
- Updated documentation to include Python version usage

### Fixed
- Various minor bugs from the initial release
- Improved reliability of DNS query handling

## [1.0.0] - 2024-07-20

### Added
- Initial release with bash implementation
- Support for checking IPs against 50+ DNS blacklists
- Basic trust score calculation
- Grouped blacklists into logical categories
- ASCII art header and Unicode box borders
- Color-coded results with visual indicators
